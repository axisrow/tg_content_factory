# TG Agent

**Зависимость для агентов кодирования: полный спектр действий с Telegram через CLI**

TG Agent — self-hosted инструмент автоматизации Telegram для агентов кодирования (Claude Code, OpenCode, Codex): агент действует в вашем Telegram (сообщения, каналы, админка, медиа) и ведёт контент-фабрику (сбор → генерация → модерация → публикация). Нативный путь — `tg-agent` CLI + скилл.

## Возможности

| Модуль | Описание |
|--------|----------|
| **tg-agent CLI** | ~250 команд на весь Telegram: чаты, каналы, сообщения, медиа, админка — каждая команда самодостаточна, демон не нужен |
| **Скилл для агентов** | Каталог команд и safety-правила для агента — [`skills/tg-agent/SKILL.md`](https://github.com/axisrow/tg_content_factory/blob/main/skills/tg-agent/SKILL.md) |
| **Каналы** | Добавление, сбор, фильтрация сотен каналов |
| **Поиск** | FTS5 полнотекстовый + семантический поиск через векторные эмбеддинги |
| **Контент-пайплайны** | Генерация контента через LLM → модерация → авто-публикация |
| **Планировщик** | Периодический сбор, поисковые уведомления, расписание публикаций |
| **Фото-загрузчик** | Батчевая отправка фото, автоматическая очередь |
| **Аналитика** | Тренды, топ-сообщения, статистика каналов, контент-аналитика |
| **Dialogs** | Реальные действия в чатах: отправка, пересылка, редактирование, участники, админы |
| **Встроенный AI-агент (легаси)** | 100+ MCP-инструментов (Claude / DeepAgents) — заморожен |

## Поверхности

**Нативно: CLI + скилл для агентов кодирования.** Новые возможности появляются в CLI первыми и тестируются там; скилл описывает агенту каталог команд и правила безопасности:

```bash
tg-agent channel list
tg-agent search "запрос" --limit 20
tg-agent pipeline run 1
```

**Легаси (работают, заморожены):** Web UI (`tg-agent serve`), TUI, встроенный AI-агент, MCP-сервер. Подробная разбивка прежней модели «пяти равноправных поверхностей» — в [Карте сервисов](feature-map.md) и [Parity-матрице](parity-matrix.md).
